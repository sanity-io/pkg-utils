Add the `@sanity/pandacss-tsdown-plugin/vite` entry, for packages that build with the plugin (directly or through the `panda` option of `@sanity/tsdown-config`) and also run their Panda sources through Vite, in a dev server, a Storybook or Vitest's browser mode, so that output behaves like the published build. It is not a standalone Vite plugin: `tsdown` stays a required peer, and its options mirror the tsdown `panda` options. Its `pandacss()` wraps the official `@pandacss/vite` plugin. With `cascadeLayers: false`, as in the tsdown config, it removes the cascade layers from the generated stylesheet with the same pass as the tsdown plugin, so the Vite output cascades like the published `bundle.css`, in `vite dev`, `vite build` and Vitest's browser mode. It also provides the stylesheet `@pandacss/vite` generates the CSS into as `virtual:panda.css`, which declares the layers of the Panda config, so it is imported instead of a hand-written stylesheet with the `@layer` statement. A `banner` option prepends CSS such as a `@layer` statement that orders other libraries' layers. `vite` and `@pandacss/vite` are optional peer dependencies, which only the new entry needs.

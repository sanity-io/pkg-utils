# @sanity/vanilla-extract-rolldown-plugin

> [!WARNING]
> This package is deprecated and no longer maintained.

vanilla-extract support was removed from [`@sanity/pkg-utils`](https://github.com/sanity-io/pkg-utils/tree/main/packages/@sanity/pkg-utils#readme) in v14 and from [`@sanity/tsdown-config`](https://github.com/sanity-io/pkg-utils/tree/main/packages/@sanity/tsdown-config#readme) in 0.32.0. The source code has been removed from this repository. Published versions stay on npm, but they won't get fixes or updates.

## Alternatives

- Use the official [vanilla-extract bundler integrations](https://vanilla-extract.style/documentation/integrations/vite/), such as `@vanilla-extract/rollup-plugin` or `@vanilla-extract/vite-plugin`.
- For library builds with `@sanity/pkg-utils` or `@sanity/tsdown-config`, plain CSS or CSS modules work through the `css` option, and Panda CSS works through the `panda` option.

See the [`@sanity/pkg-utils` migration notes](https://github.com/sanity-io/pkg-utils/blob/main/packages/@sanity/pkg-utils/MIGRATE.md#v14-vanilla-extract-support-removed).
